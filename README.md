# Cubo Trainer

A speedcubing trainer for the 3x3x3 cube, in one HTML file.

- **Timer** with random-move scrambles, optional WCA inspection, ao5/ao12/ao50/ao100 and a trend chart
- **Beginner method** walkthrough (8 steps) with animated situations
- **CFOP**: all 41 F2L, 57 OLL and 21 PLL cases with a 3D player, plus 2-look PLL
- **Notation** reference and a **Moves** sandbox where you type moves and the cube performs them

Algorithms follow [cubovelocidade.com.br](https://cubovelocidade.com.br/tutoriais).
Times and "learned" marks are saved in your browser only.

Built with [three.js](https://threejs.org/) (loaded from cdnjs).
